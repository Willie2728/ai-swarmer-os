# Wilkerson Collective WC Agent ID Standard

Every Wilkerson Collective product that contains an AI agent, AI employee, digital worker, SYNTHSAPIEN, avatar worker, sub-agent, automation worker, or agentic workforce component must give that agent both a human-readable name and a simple Wilkerson Collective Agent ID.

## Format
- Prefix: `WC`
- First 99 agents: `WC01` through `WC99`
- After 99 agents: expand naturally to `WC100`, `WC101`, etc.

## Required agent record fields
- `agentId` / `agent_id`
- `name`
- `role` or `title`
- `department`
- `specialty`
- `descriptor`
- `capabilities`
- `subAgents`
- `supervisor`
- `accessLevel`
- `operatingMode`
- `proofScore` when applicable
- `currentFocus`
- `workHistory`
- `activeWork`
- `nextActions`
- `intakeChannels`
- `exportChannels`

## Required UI behavior
The UI must support Agent ID badges, search/lookup by Agent ID, upload/feed controls, export/share controls, proof/audit trails, and the ability to answer: “What is Agent WC010 doing?”

## Differentiator
Wilkerson Collective products are not merely chatbots or hidden automations. They are identifiable digital workers with names, WC Agent IDs, visible workspaces, avatar bodies where appropriate, dashboards, proof trails, upload panels, export/share controls, and accountable operating records.
