## Deployable copy

A useful AI-agent security pilot starts with one bounded autonomous workflow and one explicit authority map.

Name the tools and connectors it may invoke. Name the sensitive destinations it can reach. Mark which actions require human approval. Mark which code, dependency, publisher, permission or fingerprint changes should expire prior trust.

Then run the control sequence: verify → inspect → isolate when needed → approve → fingerprint → observe → revalidate.

End with a control receipt: what was admitted, denied, isolated, approved, fingerprinted, observed and revalidated — plus the gaps that remain unresolved.

That is a testable pilot. It is not a promise of universal network protection.

**CTA:** Bring one autonomous workflow and its authority map. Define the pilot boundary before the demo.

## Product Truth Boundary

The connected SWARMER repository describes an operational MVP with Capability Gate controls, fingerprinting, policy enforcement, telemetry, revalidation triggers, evidence and audit history. It explicitly does not claim complete network protection or independently validated superiority. Production use still requires deployment-specific enforcement adapters and enterprise hardening.
