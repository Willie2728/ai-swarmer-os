# SWARMER + SOVRAIL + KAMERON
## Trust it. Price the whole outcome. Reuse what is already solved. Recover the work.

AI agents are gaining access to models, APIs, MCP servers, browsers, desktops, data, and business systems. Basic gateways can route calls. The WCL control plane is designed to answer harder questions.

### SWARMER
**Should this agent/capability/action be allowed at all?**
- Capability provenance and supply-chain inspection
- Claimed-vs-observed behavior
- Permissions and secret/exfiltration analysis
- Continuous revalidation
- Consequential computer-action authorization

### SOVRAIL
**What is the best approved way to complete the job?**
- Total Execution Cost Intelligence
- Session/cache-aware routing
- Local/private/cloud/commercial execution choice
- Adaptive Recipe Memory
- Budgets, quotas, failover and observability
- GearShift model comparison

### KAMERON
**If the job is interrupted, where can it safely resume?**
- Trusted checkpoints
- Recoverable execution state
- Reduced restart/recomputation cost

## GearShift: see before you shift
Gear 1 represents economical routine execution. Gear 3 represents balanced capability. Gear 5 represents the strongest approved model tier.

For important workloads, SOVRAIL can run a controlled same-task benchmark and report what each gear actually produced, how long it took, direct cost, total expected cost to reach a successful outcome, and whether the lower gear still met the required quality threshold.

No fake hypothetical answers: if a model was not actually run, its outcome is labeled as an estimate/projection only.

## The moat
The defensible combination is not simply “another AI gateway.” It is:

**SWARMER trust + SOVRAIL outcome economics + Adaptive Recipe Memory + GearShift transparency + sovereign execution + KAMERON recovery.**

### Customer-facing promise
**Don't pay your agents to relearn solved work. Don't switch models just because a token looks cheaper. Know what the tradeoff is before you shift gears. Keep agents inside authorized lanes. Keep important work recoverable.**
