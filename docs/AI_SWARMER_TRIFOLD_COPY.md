## INSIDE FLAP — THE NEW ATTACK SURFACE
### Your next employee may be software.
Enterprises are connecting AI agents to email, files, CRMs, code, cloud infrastructure, browsers, APIs and financial workflows. Those agents can inherit permissions and take actions at machine speed.

Traditional endpoint and network security remain essential. But agentic systems introduce another question:

**Should this capability be allowed to act at all?**

SWARMER is designed to answer that question before trust becomes access.

## INSIDE LEFT — THE SWARMER GATE
### Every capability is a visitor. Every visitor is verified.
Skills • MCP servers • plugins • repositories • packages • workflows • API connectors • model tools • updates

**Guest List** verifies source and identity.
**Capability Gate** inspects code, intent, dependencies and permissions.
**Risk Engine** scores dangerous patterns and excessive agency.
**Red Room** isolates suspicious capabilities for behavioral evaluation.
**Behavior Verification** compares what software says it will do with what it actually does.

## INSIDE CENTER — THE MOAT
### Trust expires when the software changes.
SWARMER creates a cryptographic capability passport for approved software: source, publisher, version, permissions, dependency state, fingerprint and approval history.

Change the code? Revalidate.
Change a dependency? Revalidate.
Expand permissions? Revalidate.
Change publisher or fingerprint? Revalidate.

The **Capability Reputation Ledger** turns isolated alerts into institutional memory — preserving what entered, what changed, what it attempted, why it was blocked and whether it should ever be trusted again.
